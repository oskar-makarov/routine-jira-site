# Publication website package

Static English overview, support and privacy draft. No app backend, scripts,
cookies, analytics or third-party assets are included. This website is separate
from the Forge runtime and does not receive app data.

The application repository is private. Never make it public to obtain policy
URLs. Publish only `index.html` on a separate static website after the owner
confirms publisher identity, support mailbox handling and the public address.
The privacy draft notice must remain until that review is completed.

On the eventual website, the relevant anchors are `/#support` and `/#privacy`.
These are not live URLs yet and must not be entered into Marketplace as if
published. A custom domain and active business email remain separate publication
requirements for the paid app. End-user terms are not included in this package.
